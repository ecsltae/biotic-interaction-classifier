# BiotXplorer: what the reframe may say, from public sources only (main session, 2026-10-05 02:10)

Public sources read (all third-party, public):
- ruch2024biotxplorer (already in references.bib): BISS 8:e135453 (2024), conference abstract, CC BY 4.0.
  Full abstract read from the publisher XML (https://biss.pensoft.net/article/135453/download/xml/).
  The Zenodo record 13382468 is a copy of the same abstract (resource type "Journal article").
- Public resource pages: Expasy resource catalogue entry and the SIBiLS tool page (descriptive one-liners only).
- No other BiotXplorer publication found (web search "BiotXplorer" 2025, "Biodiversity PMC" ... 2025).

Facts the paper can state, each with the abstract as the citation:
1. It is a public exploration tool for biotic interactions in a literature collection (Biodiversity PMC)
   processed by SIB Literature Services (gobeill2020sibils).
2. Method, verbatim: it builds "pairs of species co-occurring in the same sentence together with a biotic
   interaction concept as defined in the Relation Ontology"; a search service aggregates matching triplets and
   expands queries through taxonomic hierarchies. The public tool page: "Each identified interaction is
   accompanied by one or several relevant passages extracted from the scientific literature."
3. Its authors' own evaluation, verbatim: "Out of the 100 random triples generated by BiotXplorer, we achieved a
   precision of 31% when identifying the interacting species. For 74% of the correct interacting species, we
   accurately identified the type of interaction between the two species. The main causes of error were
   instances where passages listed multiple species, which can be automatically filtered out." Second
   benchmark (validated GloBI interactions): "85% of the returned passages confirming an interaction between the
   two species."
4. Their stated next step, verbatim: "we are working on refining the system using different post-processing
   methods, such as reducing the volumes of triples by retaining only top-ranked, and therefore most reliable,
   triples."

How this serves the reframe (application, not novelty):
- Both of the public evaluations are PAIR-in-passage judgments ("identifying the interacting species";
  "passages confirming an interaction between the two species"). The tool shows passages as evidence for a
  queried pair. So a passage shown to a user must (a) describe an interaction (sentence level) and (b) concern
  the pair it is shown for (pair level). The reframe can say: the application needs both decisions, and the
  pair verifier yields both; a sentence filter yields only (a). This is an argument from the public description,
  not from private knowledge.
- The public error diagnosis (multi-species passages) is exactly the case where sentence and pair labels diverge;
  the submission already uses it (Setting, l.103-110). The reframe can reuse it unchanged.
- The stated next step (keep top-ranked triples) is a ranking/volume reduction, not a passage-level check. The
  reframe must not characterise it further, compare against it, or predict its results (risk of overlap with
  the system authors' own forthcoming work).

Must NOT appear in any draft (anonymity and non-overlap):
- No statement that the authors of this paper work with, for, or alongside the system's team; no "our
  application", "our collaborators", "we deployed in BiotXplorer", "the BiotXplorer team asked for sentence
  level". The user's remark that the application owner "wants the sentence level" is private: the paper must
  motivate the sentence-level target from the task itself and from public curation practice (triage literature),
  not from the application owner's wishes.
- No internals beyond items 1-4: no ranking function, scoring, surface-form dictionaries beyond "taxonomy +
  Relation Ontology", interface details, usage numbers, roadmap beyond the quoted sentence, or any mention of a
  forthcoming paper. Measurements the paper itself made on candidates it retrieved (pool size, share of passages
  with interaction vocabulary) are the paper's own measurements and stay worded as such.
- No URL of the tool page in the draft (the BISS DOI is enough); no names of the system's authors in running
  text beyond the \citet{} the bibliography generates (the existing citation is a normal third-party citation).
- Caveat for the writer (not a change request to the submission): the abstract's affiliations are public. Text
  that implies privileged access to the system (unpublished grades, internal data dumps, team decisions) can
  de-anonymise; describe benchmark provenance as the submission already does and add nothing new about it.
