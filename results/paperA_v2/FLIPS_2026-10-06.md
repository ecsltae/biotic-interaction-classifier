## 2. Code changes (all made before the flips, then the regression was run)

* **src/eval/core.py**: `LABEL_VERSIONS` = `current` (unified_test_set.csv, new sha, 251),
  `pre_review_2026-10-06` (frozen copy, sha 057416..., 246) and `pre_goldfix` (frozen copy, sha
  cac7dc60..., 247); `label_version()`, `clean_mask(labels)`, `clean_benchmark(labels)` and
  `benchmark_provenance(labels)`. The mask is computed as before (`in_train` or 5-gram Jaccard > 0.5)
  and every version is hash-checked and count-checked. `CLEAN_N = 437`; `CLEAN_POS = 251` (current).
  The comment block records both gold revisions. Default arguments keep every existing caller unchanged.
* **scripts/paperA_tables.py**: loads the benchmark through `clean_benchmark(--labels)` (no private
  re-filter, no hardcoded 437/246). The base run stores `n`, `positives`, `base_rate`,
  `accept_everything` (AUPRC, P, R, F1), `positives_by_block` (n, positives, rate), `labels` and
  `benchmark_sha256`. `llm_rows` scores every LLM row against the benchmark labels `y[idx]` and
  asserts alignment on species1, species2 and sentence instead of label equality (the 32 biodiv LLM
  CSVs keep a label column that is now stale on 7 rows; it is reported on stderr and never used). A
  suffixed run stores `benchmark_sha256_<suffix>` and refuses to merge into a file scored against
  other labels; a base run keeps a suffixed key only if its suffix carries the same SHA and otherwise
  drops it and names the suffixes to rerun (the first new-label base run dropped `_soft`,
  `_linkbert`, `_linkbertL` and `_qwen38`, all rerun). `--labels` and `--out-dir` (every read and
  write, the S_*.npy included, so a regression run writes nothing into results/). Each arm's three
  per-seed score vectors are saved to `<out-dir>/per_seed/S_biodiv_<arm><suffix>.npy`, outside the
  `S_biodiv_*.npy` glob that `--llm-only` (and any copy to the mirror) uses. BioRED: same `llm_rows`;
  its LLM block reproduces all 224 existing values.
* **scripts/eval_shipping.py** and **paperA/fig/make_threshold_figure.py**: `clean_benchmark(--labels)`,
  output-directory options; the eval JSON records labels and SHA; the figure script prints how many of
  the 99 thresholds put the pair model ahead and the smallest gap (docstring: 'conditioning on the
  pair', no 'deployed filter').
* **scripts/cascade_tables.py**: `--labels`, `--out-dir`, `--bench-scores`; stores labels and SHA,
  `student_no_rules`, `rules_vs_no_rules` (McNemar), `co_listed_on_accept_set` (fires, FPs and TPs
  removed, McNemar), and for every band `model_alone_reaches_P`: the first tau in 0.50, 0.51, ..., 0.99
  at which the model plus rules alone reaches the band's precision, with its P, R, F1, FP, FN.
* **scripts/paperA_derived_numbers.py** (new) -> `results/paperA_v2/derived_biodiv.json` and
  `results/paperA_v2/false_positives_pair.csv` (same columns and row order as the committed file; it
  had no writer before). From cached scores plus `clean_benchmark(--labels)`: Table 2 strata (n,
  positives, negatives, ensemble AUPRC per arm, gains), the coinciding stratum, per-seed AUPRC and F1
  at tau = 0.5, candidate rules on the pair and triple models (P/R/F1, fixed/broken, p), the pair
  model's false positives and their counts, the Figure-4 claim, the Biotx100 GloBI/random halves, the
  positives in multi-taxon passages, Reject50 recovery, the base-sample triple model
  (models/student/xenc_s1-3: scored once on the GPU, order-free, cached in
  `per_seed/S_biodiv_triple_basesample.npy`), the deployed model's rules vs none (and co_listed), and
  the zero-shot gaps quoted in the body (teacher and scaling). It cross-checks itself against
  tables_biodiv.json (thresholds, F1, strata, per-seed AUPRC, triple-model rules) and refuses to run
  on a tables file scored against other labels. Uses paperA_tables' order_free, block_held_out, prf
  and mcnemar, and candidate_rules.
* **scripts/model_card_tables.py**: `--labels` accepts every label version (adds
  `pre_review_2026-10-06`), loaded through the hash-checked `clean_benchmark(labels)`.
* **scripts/audit_paper_numbers.py**: SOURCES no longer reads the superseded snapshots
  (tables_biodiv.pre_llm.json, tables_biored.original_protocol.json, tables_biored.pre_llmpair.json)
  or anything in results/paperA_rebuild_2026-09-28 (ablation, eval_student_v3, vs_v1_full,
  rules_eval, joint_rules_eval, rebuild_Verifier-*, and also rebuild_Sentence-baseline.json, which is
  old-label and superseded by derived_biodiv.json's per-seed F1 at tau = 0.5; decision recorded here);
  derived_biodiv.json and cascade.json are named explicitly. NUM now also matches numbers without a
  leading zero (`.858`, `_{\pm .006}`). On the current, not yet updated draft it checks 904 numbers
  (799 before) and leaves 73 unexplained (49 before): the stale old values no longer look explained.
